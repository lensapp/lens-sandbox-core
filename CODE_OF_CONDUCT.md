# Code of Conduct

We want `lens-sandbox-core` to be a professional, respectful, and useful open-source project.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent while staying precise about technical risks.
- Keep discussions focused on the code, documentation, architecture, or security question at hand.
- Be especially careful and evidence-driven in security-related discussions.

## Unacceptable Behavior

- Harassment, threats, or personal attacks
- Discriminatory language or behavior
- Publishing private information without permission
- Publicly disclosing suspected vulnerabilities before maintainers have had a reasonable chance to respond

## Reporting

For conduct concerns, contact the maintainers through the repository owner channels.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md).
